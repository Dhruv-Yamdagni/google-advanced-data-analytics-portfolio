# Google Advanced Data Analytics Capstone Portfolio

This repository contains end-to-end data analytics and data science projects developed across the **Google Advanced Data Analytics Professional Certificate**. Each track follows the **PACE (Plan, Analyze, Construct, Execute)** framework to solve distinct business problems from raw data ingestion to machine learning.

## Methodology: PACE Framework
* **Plan:** Understand business objectives, define analytical questions, and evaluate data scopes.
* **Analyze:** Clean raw data, address anomalies/missing values, and perform Exploratory Data Analysis (EDA).
* **Construct:** *(Upcoming)* Apply hypothesis testing, statistical inference, and machine learning models.
* **Execute:** Synthesize findings into actionable stakeholder summaries and production code.
